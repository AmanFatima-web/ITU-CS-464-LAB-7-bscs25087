# Mobile Game Menu System

## Project Overview
This project is a complete mobile game menu system developed in Unity. It contains 10 distinct and logically connected screens with functional buttons and navigation.

## Screens Included
1. Splash Screen
2. Main Menu
3. Mode Selection
4. Level Selection
5. Settings
6. Pause Menu
7. Results Screen
8. Character Selection
9. Shop Screen
10. Credits Screen

## Features
- 10 interactive game menu screens.
- Functional button navigation between screens.
- Smooth fade-in and fade-out transitions.
- Character selection and confirmation.
- Music and sound effects settings.
- Shop purchase confirmation.
- Win and Lose result screens.
- Grayscale design evaluation.
- Annotated colour screenshots.

## Unity Version
This project was developed using Unity 6.2 (6000.2.6f2).

## Setup and Run Instructions
1. Download or clone the project repository from GitHub.
2. Open Unity Hub.
3. Click **Add Project from Disk** and select the downloaded project folder.
4. Open the project using Unity 6.2 (6000.2.6f2).
5. Open the main game scene from the Scenes folder.
6. Press the Play button in Unity to run the project.

## Project Requirements
- Unity 6.2 (6000.2.6f2)
- TextMeshPro
