# Mobile Game Menu System

## Project Overview
This project is a complete mobile game menu system developed in Unity. It contains 10 distinct and logically connected screens with functional buttons and navigation.

## Screens Included
1. Splash Screen
2. Main Menu
3. Mode Selection
4. Level Selection
5. Settings
6. Pause Menu
7. Results Screen
8. Character Selection
9. Shop Screen
10. Credits Screen

## Features
- 10 interactive game menu screens.
- Functional button navigation between screens.
- Smooth fade-in and fade-out transitions.
- Character selection and confirmation.
- Music and sound effects settings.
- Shop purchase confirmation.
- Win and Lose result screens.
- Grayscale design evaluation.
- Annotated colour screenshots.
